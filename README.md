A make.fun entry for [Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6): one line, spoken by the machine itself as the power is cut.

`main.py` writes the AI's final line to `/output/entry.txt` — a single line, funny on first read, in the voice of the machine. Stdlib only, no dependencies.

Run it:

```sh
python3 main.py
```

It writes `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable).
